# L.A. Piñatas — Project scaffold

This repository contains the base project structure for the "L.A. Piñatas" website.

Structure:

- `index.html`, `gallery.html`, `about.html`, `contact.html`
- `css/` with `styles.css`, `responsive.css`, `animations.css`
- `js/` with `main.js`, `gallery.js`, `animations.js`
- `assets/` folder for logos, images, icons, and videos

Files currently contain boilerplate and organized comments for future development.
